# Temper Docs

Temper is a mobile gym tracking app for logging workouts, building programs, and tracking progress.

## Program Import

You can generate a workout program with an AI tool and import it directly into Temper.

- [Program Import Guide](program-import/) — how it works and what fields are supported
- [JSON Schema](program-import/schema.json) — machine-readable schema for the import format
- [Prompt Template](program-import/prompt.md) — copy-paste prompt for ChatGPT, Claude, Gemini, etc.
- [Examples](program-import/examples/) — complete example programs in JSON
