# temper-docs

Public documentation for Temper — a mobile gym tracking app.

This repo hosts the **Temper Program Import Format** docs, schema, and examples. It is served via GitHub Pages at [kyle-pierce.github.io/temper-docs](https://kyle-pierce.github.io/temper-docs).

## What's here

- **[Program Import Guide](program-import/)** — how to generate JSON programs that Temper can import
- **[Schema](program-import/schema.json)** — machine-readable JSON Schema for the import format
- **[Prompt Template](program-import/prompt.md)** — copy-paste prompt for ChatGPT, Claude, Gemini, etc.
- **[Examples](program-import/examples/)** — complete example programs in JSON

## Purpose

The Temper mobile app is not hosted on the web and the main app repo is private. This public repo gives AI tools, coaches, and users a stable URL to reference when generating Temper-compatible programs.

## Contributing

This repo is maintained by the Temper team. Schema and exercise catalog updates are synced automatically from the main app repo.
